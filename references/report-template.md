# 报告模板

在最终回答中使用此结构。保持简洁，但不要省略结论部分。

## 症状

- 用户观察到什么
- 相关时间窗口
- 使用的命令或证据

## 各领域证据

### CPU

- 系统级证据
- 进程级证据
- CPU 是主要、次要还是不是主要问题

### 内存

- 系统级证据
- 进程级证据
- 内存是主要、次要还是不是主要问题

### I/O

- 系统级证据
- 进程级证据
- I/O 是主要、次要还是不是主要问题

### 网络

- 系统级证据
- 进程级证据
- 网络是主要、次要还是不是主要问题

## 结论

明确说明以下三项：

1. 主要瓶颈：CPU、内存、I/O 还是网络。
2. 瓶颈层：内核态还是应用态。
3. 触发进程：主要应用程序进程，如果问题无法归因于用户态进程则写 `none identified`。
